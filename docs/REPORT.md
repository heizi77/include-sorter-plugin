## Цель работы

Изучить механизм подключения расширений в VS Code и реализовать команду обработки текста в редакторе.

## Постановка задачи

Разработать команду для сортировки выделенного блока директив `#include`. Команда должна разделять заголовки по виду подключения, удалять повторные строки и сортировать пути в каждой группе. При неподходящем выделении команда должна выводить предупреждение, сохраняя исходный текст.

## Реализация

Расширение написано на JavaScript. Команда и точка входа описаны в `package.json`. При запуске команды VS Code загружает расширение в Extension Host и вызывает функцию `activate`. Функция регистрирует обработчик, который получает активный документ и выделенный диапазон через API редактора.

Логика сортировки вынесена в отдельный модуль. Он проверяет каждую строку и распределяет директивы между двумя структурами `Map`. Каждая структура хранит путь заголовка и первую строку, где он встретился. После сортировки путей модуль возвращает строки, а обработчик заменяет диапазон одной правкой. Функции снабжены комментариями. Полное ТЗ и блок-схема приведены в [документации проекта](PROJECT.md).

## Демонстрация

1. Запустить расширение через **F5**.
2. Открыть пример из [README](../README.md#пример), выделить пять строк с директивами и запустить **C/C++: Sort Selected Includes**.
3. Показать, что `<algorithm>` и `<vector>` идут первыми, следом идут `"a.h"` и `"z.h"`, а повтор `<vector>` удалён.
4. Выполнить Undo. Затем выделить блок вместе со строкой `int main() {}` и снова запустить команду. Проверить предупреждение и сохранение текста.
