# C/C++ Include Sorter

Расширение для **Visual Studio Code**. Команда **C/C++: Sort Selected Includes** сортирует директивы `#include` в выделенном блоке.

**Автор** — *Сапожников Михаил Анатольевич* 

**Группа** — *M3104*

## Возможности

- Размещает `#include <...>` перед `#include "..."` и сортирует заголовки внутри каждой группы по имени с учётом регистра.
- Удаляет дубликаты внутри каждой группы. Сохраняет первую строку с данным именем заголовка.
- Применяет сортировку одним действием. Исходный блок можно вернуть через Undo.
- Сообщает об ошибке, если выделение неполное или содержит строки другого формата.

Выделяйте полные строки отдельного блока в файле C или C++. Выделение может заканчиваться в конце последней строки или в начале следующей. Поддерживаются прямые директивы без пустых строк, комментариев и макросов в блоке. Выбирайте блок, в котором порядок заголовков можно менять.

## Запуск

1. Откройте папку проекта в VS Code 1.74 или новее.
2. Нажмите **F5** или выберите **Run Include Sorter** в панели **Run and Debug**. Откроется окно Extension Development Host.
3. В новом окне откройте файл C/C++ или создайте новый файл и установите режим языка **C++**.
4. Вставьте пример ниже и выделите первые пять строк целиком.
5. Откройте палитру команд (`Cmd+Shift+P` на macOS, `Ctrl+Shift+P` на Windows и Linux) и выполните **C/C++: Sort Selected Includes**.

Для запуска из исходников достаточно VS Code.

### Пример

Вход:

```cpp
#include "z.h"
#include <vector>
#include "a.h"
#include <vector>
#include <algorithm>
int main() {}
```

После сортировки:

```cpp
#include <algorithm>
#include <vector>
#include "a.h"
#include "z.h"
int main() {}
```
